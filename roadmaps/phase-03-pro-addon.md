# فاز ۳ — افزونهی Pro و فضاهای ابری

> **Status:** ⚪ todo · **Progress:** ۰٪ · **پیشنیاز:** فاز ۲ (لایسنس)
> **مسیر:** `pro/` در همین مخزن توسعه مییابد و به مخزن/محصول جداگانهی `backupino-pro` منتقل میشود.

## هدف

همه قابلیتهای پولی در قالب یک افزونه مکمل و افزودنی سبک (Addon) در کنار هسته رایگان، متصل از طریق فیلترها و هوک‌ها بدون تکرار کد.

## تسکها (پیشنویس)

| ID | تسک | توضیح |
|---|---|---|
| P3-T01 | فعالسازی لایسنس در Pro | صفحهی لایسنس، اتصال به دامنه، کش امضاشده |
| P3-T02 | اعمال محدودیت دامنه | ۱/۱۰/۳۰ + آزادسازی و معلقسازی ۷۲ ساعته |
| P3-T03 | درایور S3 (منتقلشده) | بازگرداندن `pro/src/Storage/S3*` و ثبت با فیلتر |
| P3-T04 | Google Drive | OAuth در پنل + توکن کوتاهعمر + آپلود مستقیم |
| P3-T05 | هاست دانلود (FTP/SFTP) | درایور جدید |
| P3-T06 | ابر اختصاصی Backupino | کلاینت API + سهمیه |
| P3-T07 | سیاستهای retention پلنی | ۲/۵/۱۰ نسخه روی هر مقصد |
| P3-T08 | زمانبندی پیشرفته | ساعتی/روزانه/هفتگی + زنجیرهی «بکاپ → آپلود → پاکسازی محلی» |
| P3-T09 | ریاستور درجا + rollback | اسنپشات قبل از بازگردانی |
| P3-T10 | مالتیسایت | بکاپ شبکه + زیرسایتها |
| P3-T11 | بکاپ افزایشی | مقایسه با مانیفست قبلی |
| P3-T12 | وایتلیبل | حذف برند از اینستالر/ایمیلها |

## قاعدهی جدا نشدن

هیچ کد `pro/` به کلاسهای `free/` import مستقیم نمیزند؛ فقط اینترفیسها و فیلترهای مستند:

| نقطهی اتصال | کاربرد |
|---|---|
| `backupino_storage_drivers` | ثبت درایور مقصد |
| `backupino_stages` | افزودن مرحله به خط لوله |
| `backupino_job_completed` | پس از پایان موفق |
| `backupino_limits` | اعمال محدودیت پلن |
