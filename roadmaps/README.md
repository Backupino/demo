## علائم وضعیت

| علامت | معنی |
|---|---|
| ⏳ `todo` | هنوز شروع نشده |
| 🔄 `in-progress` | در حال توسعه |
| 🔄 `reopened` | تکمیلشده بود، تسک تازهای به آن اضافه شد |
| ✅ `done` | تکمیل شده و تستها سبز |
| 🛑 `blocked` | متوقف روی وابستگی خارجی |

## قوانین
