## قاعده

هر تسک فقط وقتی `done` میشود که: کد + تست‌های مرتبط با تسک سبز + رعایت خودکفایی ۱۰۰٪ محلی و آفلاین + مستندات بهروز + (با تأیید) کامیت. مجموعه کامل رگرسیون تست‌ها در پایان کل فاز ارزیابی می‌شود. جزئیات: [`docs/Dev/DEVELOPMENT-RULES.md`](../docs/Dev/DEVELOPMENT-RULES.md)
