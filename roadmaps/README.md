## قوانین

هر تسک قبل از اینکه `done` شود باید: کد + تست‌های متناسب با همان تسک + آپدیت مستندات در نقشه و تصمیمات + تست‌های نحوی + (در صورت نیاز) بازسازی. برای فاز رایگان، سخت‌گیری کامل روی چک‌لیست مخزن وردپرس اعمال می‌شود. مرجع: [`docs/Dev/DEVELOPMENT-RULES.md`](../docs/Dev/DEVELOPMENT-RULES.md)
