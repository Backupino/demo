## هدف

زیرساخت تجاری: حساب کاربری، فروش پلن، صدور لایسنس، پنل مدیریت چندسایتی، ربات مرکزی و پشتیبانی.

## تسکها (پیشنویس)

| ID | تسک | توضیح |
|---|---|---|
| P2-T01 | قرارداد API افزونه ↔ پنل | activate/validate/heartbeat/deactivate، دریافت پلن و سهمیه، لیست بکاپها |
| P2-T02 | سرویس لایسنس با امضای سرور | کلید عمومی در افزونه/Pro، پاسخ JSON امضاشده |
| P2-T03 | حساب کاربری | ثبتنام، ورود، احراز موبایل + جیمیل، پروفایل |
| P2-T04 | فروش و پرداخت | درگاه ایرانی + بستههای حجم/دامنه، فاکتور، تمدید |
| P2-T05 | پنل چندسایتی | پوشه/دسته برای سایتها، دامنهها، آخرین بکاپها، لینک دانلود |
| P2-T06 | مدیریت اتصال ابرها | فرم اتصال S3/Drive، تست اتصال، دریافت توکن کوتاهعمر |
| P2-T07 | ربات مرکزی + کد اتصال | `/link CODE`، اعلان هر سایت، mute، وضعیت |
| P2-T08 | سیستم تیکت | پشتیبانی داخل پنل |
| P2-T09 | اعلانات و ایمیل | اعلان پایان اشتراک، دانلود، خطای بکاپ |
| P2-T10 | سرویس ابر اختصاصی | باکت S3 داخلی + سهمیه ۳۰/۱۰۰GB + پاکسازی پس از ۶۰ روز |
| P2-T11 | تبدیل افزونه به کانال ربات مرکزی | افزودن `Notify\CentralBotChannel` کنار کانال شخصی |
