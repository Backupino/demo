# فاز ۵ — ربات مرکزی «فاز مستقل»

> **Status:** ⏳ todo · **Progress:** ۰٪ · **Last updated:** 2026-11-04
> **پیشنیاز:** API فاز ۳ و منبع رویداد فاز ۴ آماده باشند.
> **قانون طلایی:** ربات مرکزی **مطلقاً شامل نسخهٔ رایگان نمیشود**؛ فقط Pro، **پیشفرض غیرفعال**، و فعالسازیاش از پنل کاربری است `D-009 اصلاحشده` / `D-033` / `D-040`.
> **عامل مسئول فاز:** `AG-BOT` · **پاسخگو:** `AG-ORCH` · **مشورت:** `AG-PORTAL` / `AG-UI` / `AG-QA` / `AG-DOCS` · **قرارداد تخصیص:** [`AGENT-CONTRACT.md`](AGENT-CONTRACT.md)

## چرا فاز جدا؟

ربات فقط «ارسال پیام» نیست؛ یک محصول چندمستأجری است: هویت و کد اتصال، پلتفرم، مسیریابی رویداد، صف و تابآوری، اپراتوری، حریم خصوصی و انتشار مستقل. `P2-T11` قدیم «افزودن `Notify\CentralBotChannel` به **افزونهٔ رایگان**» حذف شد، چون با `D-002`، `D-020` و `readme.txt` §External Services ناسازگار بود. هستهٔ رایگان همان ربات **شخصی** Telegram/Bale خود را نگه میدارد.

## ترتیب پیادهسازی

| گام | پلتفرم | دلیل |
|---|---|---|
| `5A` | **Telegram** اول | ساختار مرجع، مستندات و `parse_mode=HTML` کاملتر |
| `5B` | **انتقال به Bale** | همان هسته، فقط base URL `tapi.bale.ai`، `parse_mode=Markdown` و قالبهای نگارشی فرق میکند «`D-018`» |

هیچ بازنویسیای انجام نمیشود: یک `BotTransport` + دو آداپتر پیکربندیشده + دو `TemplateRenderer`.
