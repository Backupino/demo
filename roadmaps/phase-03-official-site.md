## هدف

ساخت **سایت رسمی کاملاً وردپرسی** با `Elementor` + `Elementor Pro` + `WooCommerce`، شامل پنل مدیریت مشتری و اپراتور، سیستم فروش و تمدید لایسنس، و هماهنگی نسخهٔ رایگان و Pro — در سبکترین حالت ممکن، با استانداردهای `UI/UX`، `SEO` و `GEO`، انیمیشنهای سبک و CSS شیشهای مدرن.

### بودجهٔ عملکرد «معیار پذیرش»

`LCP < 2.5s` · `CLS < 0.1` · `INP < 200ms` · Lighthouse ≥ ۹۰ موبایل · CSS بحرانی `< ۵۰KB` · کل CSS `< ۱۲۰KB` · JS بار اول `< ۱۰۰KB` · `< ۶۰` درخواست · اسکریپتهای Elementor/Woo در صفحات بیتاربط `wp_dequeue_*` شوند · `wc-cart-fragments` فقط سبد/چکاوت · فونت محلی با `font-display: swap` · WebP/AVIF · `loading="lazy"` · `content-visibility: auto` · کش صفحه + Object Cache + HPOS · **هیچ فونت/آیکن/آنالیتیکس/CDN third-party پیشفرض**.

### زبان، جهت و فونت

- `en_US` **پیشفرض**، `fa_IR` **۱۰۰٪** «شامل ایمیلهای ووکامرس، صفحهٔ حساب، خطاها و متنهای المنتور؛ صفر رشتهٔ ترجمهنشده».
- `<html lang dir>`، `hreflang en/fa` روی صفحات عمومی، `noindex` برای حساب/لایسنس، `llms.txt` و schema با `inLanguage`.
- **۲ فایل فونت محلی جدا** از `Elementor Pro Custom Fonts`: یکی `fa`/RTL، یکی `en`/LTR؛ دو `@font-face` با `unicode-range` جدا، `font-display: swap`، توکنهای `--bk-font-fa` و `--bk-font-latin`؛ بدون Google Fonts / CDN / `@import`.
- جهتدهی فقط با ویژگیهای منطقی `margin-inline-*`، `padding-inline-*`، `border-inline-*`، `inset-inline-*`，`text-align: start/end`؛ آینهسازی آیکنها؛ `prefers-reduced-motion`.

### SEO و GEO «هر دو معنا»

- **SEO:** HTML معنایی، `SoftwareApplication` / `Product` / `Offer` / `FAQPage` / `Organization` / `Breadcrumb`، canonical، sitemap، پیوندسازی داخلی، پرملینک تمیز، جلوگیری از CLS ناشی از انیمیشن.
- **GEO موتورهای مولد:** موجودیت یکدست «Backupino / بکاپینو»، نسخه/تاریخ صریح، جداول مقایسهٔ ماشینخوان، FAQ واقعی و قابل استناد، `llms.txt` دوزبانه، مشخصات فنی بدون اغراق، بدون cloaking.
- **GEO جغرافیایی:** `fa_IR`/`en_US`، RTL واقعی، تقویم جلالی + ارقام لاتین، درگاه ایرانی + جایگزین بینالمللی، **بدون ردیابی IP/موقعیت**.

### UI/UX و شیشهای

Design Tokenها بهعنوان تنها منبع حقیقت؛ grid ۸px؛ کنتراست WCAG 2.2 AA؛ `focus-visible`؛ ناوبری کیبورد؛ شیشهای فقط روی سطوح کوچک «کارت/هدر/مودال» با `backdrop-filter: blur(10–14px)` و **fallback رنگ توپر**؛ بلیور تمامصفحه ممنوع؛ انیمیشن فقط `transform`/`opacity` با `۱۵۰–۲۵۰ms` و `IntersectionObserver`؛ بدون GSAP/Lottie/پارالاکس؛ اسکلت لودر، حالت خالی و پیام خطای قابلفهم.
