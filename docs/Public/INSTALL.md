# نصب و فعالسازی

> **Status:** draft (همراه با انتشار `v1.0.0` نهایی میشود)

## ۱) نصب

**از پیشخوان وردپرس**

1. پیشخوان → افزونهها → افزودن → جستوجوی «Backupino»
2. نصب → فعالسازی

**دستی**

1. فایل zip را از صفحهی افزونه یا GitHub Releases دانلود کنید
2. پیشخوان → افزونهها → افزودن → بارگذاری افزونه → انتخاب فایل → نصب
3. فعالسازی

## ۲) اولین بکاپ

1. پیشخوان → **Backupino**
2. دکمهی **ساخت بکاپ** را بزنید
3. نوار پیشرفت را ببینید؛ اگر صفحه را ببندید، بکاپ در پسزمینه ادامه مییابد و با ورود بعدی از همان نقطه ادامه داده میشود
4. پس از پایان: بسته در **Bکاپها** ظاهر میشود و لینک دائمی دانلود فعال است

## ۳) تنظیم اعلان (اختیاری)

- [راهنمای ساخت ربات](BOT-SETUP.md) را ببینید
- پیشخوان → Backupino → تنظیمات → بخش «اعلان»
- سرویس را انتخاب کنید (**تلگرام** یا **بله**)، سپس توکن ربات و شناسه‌ی عددی چت را وارد کنید
- دکمهی **ارسال پیام آزمایشی** را بزنید

## ۴) بکاپ خودکار

تنظیمات → زمانبندی → **بکاپ خودکار ماهانه** را روشن کنید. اولین اجرا در اول ماه بعدی است
(ماه شمسی اگر زبان سایت فارسی باشد، در غیر این صورت میلادی).

> ⚠️ بکاپ خودکار به بازدید سایت وابسته است (WP-Cron). اگر سایت کمبازدید است،
> در `wp-config.php` مقدار `DISABLE_WP_CRON` را `false` بگذارید یا یک cron واقعی روی سرور تنظیم کنید:
> `*/15 * * * * wget -q -O - https://example.com/wp-cron.php?doing_wp_cron`

## ۵) بازیابی روی سرور جدید

1. بستهی `site.zip` و `installer.php` را در یک پوشهی خالی روی هاست جدید آپلود کنید
2. آدرس `installer.php` را در مرورگر باز کنید
3. مراحل: بررسی محیط → اتصال دیتابیس → استخراج → ایمپورت → جایگذاری آدرس → ساخت `wp-config.php`
4. در پایان، اینستالر خودش را حذف کنید

## نیازمندیهای هاست

| مورد | توصیه |
|---|---|
| `max_execution_time` | حداقل ۳۰ ثانیه (افزونه هر tick خودش را متوقف میکند) |
| `memory_limit` | ۱۲۸ مگابایت یا بیشتر |
| فضای دیسک | حداقل ۲ برابر حجم سایت |
| دسترسی نوشتن | `wp-content/uploads` |
