# Backupino — بکاپ، کلون و انتقال سایت وردپرس

> **Status:** در حال توسعه — نسخهی رایگان `v1.0.0` · **آخرین بهروزرسانی:** 2026-10-31

Backupino کل سایت شما — **فایلها و دیتابیس** — را در یک بستهی واحد میبندد و یک
فایل `installer.php` کنارش میگذارد. با همان دو فایل، سایت روی یک سرور خالی بالا میآید؛
**بدون اینکه وردپرس نصب باشد**.

## چرا Backupino؟

- **روی هاستهای واقعی کار میکند** — بکاپ به تکههای کوچک شکسته میشود، پس محدودیت ۳۰ ثانیهای PHP کار را نمیسوزاند.
- **بدون `mysqldump` و `exec`** — دیتابیس با کد خود افزونه دامپ میشود.
- **لینک دائمی دانلود** — همیشه به آخرین بکاپ دسترسی دارید، بدون تاریخ انقضا.
- **اعلان در تلگرام و بله** — لینک بکاپ همانجا، در پیامرسان، برای مدیر سایت.
- **جایگذاری آدرس آگاه** — دادههای سریالایزشده و JSON سالم میمانند.

## چه چیزی رایگان است؟

بکاپ کامل، بدون سقف حجم، دانلود، لینک دائمی، اعلان تلگرام/بله و یک بکاپ خودکار ماهانه.
هیچ قابلیتی در نسخهی رایگان تاریخ انقضا ندارد.

ماژولهای ابری (گوگل درایو، آروان، پارسپک، ابر اختصاصی) و ریاستور درجا، بخشی از نسخهی Pro
هستند و **کدشان در نسخهی رایگان وجود ندارد**.
