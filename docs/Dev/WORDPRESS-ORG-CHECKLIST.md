# چکلیست انطباق با WordPress.org

> **Status:** active · **Last updated:** 2026-10-31
> **Referenced by:** [`DEVELOPMENT-RULES.md`](DEVELOPMENT-RULES.md) بند ۱۲
> این چکلیست پیش از **هر** ساخت بستهی انتشار اجرا میشود. هر ❌ یک توقف است.

---

## ۱) مجوز و کد

- [ ] همهی فایلهای `free/` با GPLv2+ سازگارند و سرصفحهی مجوز دارند
- [ ] هیچ کتابخانهی ناسازگار با GPL در بسته نیست
- [ ] کد خوانا است؛ بدون مبهمسازی، minify یا نامهای بیربط
- [ ] ابزارهای ساخت در readme مستند شدهاند

## ۲) Trialware (بند ۵)

- [ ] هیچ قابلیتی در `free/` با لایسنس قفل نشده
- [ ] هیچ قابلیتی با گذشت زمان یا رسیدن به سهمیه غیرفعال نمیشود
- [ ] نسخهی رایگان بدون هیچ سرور بیرونی کامل کار میکند
- [ ] هیچ کد ابری/لایسنسی در بسته نیست (`pro/` حذف شده)

## ۳) سرویس (بند ۶) و حریم خصوصی (بند ۷)

- [ ] هر تماس بیرونی (تلگرام/بله) در بخش «External services» فایل `readme.txt` افشا شده
- [ ] سیاست حریم خصوصی لینک شده
- [ ] ارسال داده فقط با اقدام صریح کاربر (توکن/chat id خودش) انجام میشود
- [ ] هیچ ردیابی، تلمتری یا آنالیتیکس پنهانی وجود ندارد

## ۴) پیشخوان (بند ۱۱)

- [ ] حداکثر یک اعلان قابل بستن در پیشخوان
- [ ] هیچ تغییر اجباری منو/ویجت/صفحهی خوشآمد مزاحم نیست
- [ ] دکمهی ارتقا در جای منطقی و غیرمزاحم است

## ۵) امنیت

- [ ] هر مسیر REST دارای `permission_callback` و بررسی nonce
- [ ] هر ورودی sanitize، هر خروجی escape، هر کوئری با `prepare`
- [ ] zip-slip در استخراج و ایمپورت مسدود است
- [ ] لینک دانلود عمومی: کلید رازدار + اجبار لاگین
- [ ] هیچ `eval`, `exec`, `system`, `extract()` روی ورودی کاربر نیست

## ۶) کیفیت و تجربه

- [ ] تستها روی PHP 7.4، 8.0، 8.3، 8.4 سبزند
- [ ] روی WP 6.0 و آخرین نسخه نصب و تست شده (`Tested up to` درست است)
- [ ] فعالسازی و غیرفعالسازی بدون خطا و بدون «هشدار خروجی»
- [ ] حذف افزونه، جدولها و آپشنهای خودش را پاک میکند (بدون آسیب به بقیه)
- [ ] `readme.txt` معتبر است (عنوان، Description، Installation، FAQ، Changelog، Upgrade Notice)

## ۷) زبان، جهت و اعداد

- [ ] همهی رشتهها با text domain `backupino` ترجمهپذیرند
- [ ] `languages/backupino.pot` بهروز و در بسته موجود است
- [ ] رابط در `fa_IR` فارسی و RTL و در `en_US` انگلیسی و LTR است
- [ ] تاریخها در فارسی شمسی و در انگلیسی میلادی نمایش داده میشوند
- [ ] همهی اعداد لاتین (`0-9`) هستند — هیچ رقم فارسی/عربی دیده نمیشود

## ۸) بسته

- [ ] ریشهی zip دقیقاً `backupino/` است
- [ ] `pro/`, `tests/`, `docs/`, `tools/`, `roadmaps/`, `.github/`, `node_modules/` حذف شدهاند
- [ ] نسخه در `backupino.php`، `readme.txt` و `CHANGELOG.md` یکسان است
- [ ] فایلهای ناخواسته (`.DS_Store`, `*.log`, `*.zip` اضافی) وجود ندارند
