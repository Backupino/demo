## 3. قواعد «دامنه»

1. یک دامنه = `home_url` بدون `www`، بدون پروتکل و بدون مسیر. زیردامنه (`shop.example.com`) دامنهی مستقل است.
2. دامنه حساب **نمیشود**: `localhost`، `*.test`، `*.local`، `*.dev`، IP خام، و حداکثر ۲ محیط staging که از پنل علامت خوردهاند.
3. مالتیسایت = **یک** دامنه (کل شبکه).
4. تغییر دامنه از پنل، بدون تیکت؛ لایسنس دامنهی قبلی فقط پس از تأیید آزاد میشود.
5. دامنهی آزادشده تا **۷۲ ساعت** «معلق» است و بعد اسلات را آزاد میکند.

## 4. سهمیه و retention

- **ابر مشتری** (Drive / آروان / پارسپک / هاست دانلود): تا N نسخهی آخر هر دامنه؛ هزینه با مشتری، برای ما صفر.
- **ابر اختصاصی**: آخرین N نسخهی هر دامنه، با سقف سخت حجمی (۳۰/۱۰۰GB).
  - رسیدن به ۸۰٪ → اعلان در ربات
  - رسیدن به ۱۰۰٪ → توقف آپلودهای **جدید** به ابر اختصاصی؛ بکاپ محلی ادامه دارد
  - هیچ فایلی بدون اخطار حذف نمیشود؛ قدیمیترین نسخهی همان دامنه اول حذف میشود.

## 5. چرخهی عمر لایسنس

```
فعال → ۳ روز مانده (اعلان) → منقضی (۷ روز مهلت کامل)
   → بازگشت به رایگان + اعلان «اشتراک تمام شد»
   → دسترسی خواندنی به آخرین بکاپها و لینک دانلودشان
   → داده روی ابر اختصاصی: ۶۰ روز نگهداری با ۳ اخطار، سپس حذف
```

- اعتبارسنجی: **سند لایسنس امضاشده با `Ed25519`** «کلید خصوصی فقط پنل، کلید عمومی ۳۲ بایتی در Pro»؛ مدل `B` هیبرید pull-first، کش ۷روزه و heartbeat **اختیاری**. هیچ تماس اجباری از هستهٔ رایگان `D-031`/`D-032`.
- آفلاین: کش ۷ روزه؛ پس از آن فقط قابلیتهای **جدید** Pro متوقف میشود، داده دستنخورده میماند.
- پلنها بهصورت **داده** (JSON امضاشده) میآیند، نه کد؛ تغییر سهمیه بدون انتشار نسخهی جدید ممکن است.
- **ریکاوری `D-044`:** `wrapped_DEK` + عبارت بازیابی یکبارنمایش + **Shamir ۲از۳ برای همهٔ پلنها** «شامل Trial و شخصی»؛ escrow HSM فقط لایهٔ اختیاری سازمانی. ما بهتنهایی قابل خواندن بکاپها نیستیم «فاز ۷».

## 8. چرخهٔ بازگردانی امن از پنل «فاز ۴»

| گام | رفتار |
|---|---|
| اسنپشات | بکاپ کامل وضعیت فعلی + هش + `wp-config` + blob لایسنس؛ **پیشفرض ۴۸ ساعت**، قابلتنظیم `۱h…۳۰d`، پاک نشدن تا تأیید معلّق |
| Shadow | استخراج در پوشهٔ جدا + جداول با پیشوند موقت؛ **سایت زنده دستنخورده** |
| پیشنمایش | لینک توکندار `noindex/no-store` + چک سلامت، گزارش فقط به **مالک حساب** |
| ✅ تأیید اول | ۲FA + کد یکبارمصرف + «اعمال روی سایت وردپرسی فعلی» |
| Commit | `RENAME TABLE` اتمیک + ژورنال فایلها + بازنویسی `wp-config` حفظشده + تزریق مجدد لایسنس |
| ✅ تأیید دوم | تأیید سلامت بعد از اعمال؛ با آن اسنپشات زودتر آزاد شود، وگرنه تا ۴۸h کامل میماند |
| Rollback | معکوس جدولها + بازگردانی ژورنال در صورت خطا/لغو |

عامل اجرا `backupino-rescue.php` در ریشهٔ سایت، بدون بوت وردپرس و فقط با درخواست **خروجی** امضاشده؛ پنل هرگز به سایت مشتری inbound نمیشود. ربات مرکزی فقط گزارش میفرستد و دستوری صادر نمیکند.
