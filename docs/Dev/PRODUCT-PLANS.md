## 3. قواعد «دامنه»

1. یک دامنه = `home_url` بدون `www`، بدون پروتکل و بدون مسیر. زیردامنه (`shop.example.com`) دامنهی مستقل است.
2. دامنه حساب **نمیشود**: `localhost`، `*.test`، `*.local`، `*.dev`، IP خام، و حداکثر ۲ محیط staging که از پنل علامت خوردهاند.
3. مالتیسایت = **یک** دامنه (کل شبکه).
4. تغییر دامنه از پنل، بدون تیکت؛ لایسنس دامنهی قبلی فقط پس از تأیید آزاد میشود.
5. دامنهی آزادشده تا **۷۲ ساعت** «معلق» است و بعد اسلات را آزاد میکند.

## 4. سهمیه و retention

- **ابر مشتری** (Drive / آروان / پارسپک / هاست دانلود): تا N نسخهی آخر هر دامنه؛ هزینه با مشتری، برای ما صفر.
- **ابر اختصاصی**: آخرین N نسخهی هر دامنه، با سقف سخت حجمی (۳۰/۱۰۰GB).
  - رسیدن به ۸۰٪ → اعلان در ربات
  - رسیدن به ۱۰۰٪ → توقف آپلودهای **جدید** به ابر اختصاصی؛ بکاپ محلی ادامه دارد
  - هیچ فایلی بدون اخطار حذف نمیشود؛ قدیمیترین نسخهی همان دامنه اول حذف میشود.

## 5. چرخهی عمر لایسنس

```
فعال → ۳ روز مانده (اعلان) → منقضی (۷ روز مهلت کامل)
   → بازگشت به رایگان + اعلان «اشتراک تمام شد»
   → دسترسی خواندنی به آخرین بکاپها و لینک دانلودشان
   → داده روی ابر اختصاصی: ۶۰ روز نگهداری با ۳ اخطار، سپس حذف
```

- اعتبارسنجی: پاسخ سرور **امضاشده** با کلید خصوصی؛ افزونه با کلید عمومی داخل خودش بررسی میکند.
- آفلاین: کش ۷ روزه؛ پس از آن فقط قابلیتهای **جدید** Pro متوقف میشود، داده دستنخورده میماند.
- پلنها بهصورت **داده** (JSON امضاشده) میآیند، نه کد؛ تغییر سهمیه بدون انتشار نسخهی جدید ممکن است.
