# pro/ — معوق (Parked) — نسخهی تجاری

این پوشه **هرگز** در بستهی افزونهی رایگان (که در WordPress.org منتشر میشود) قرار نمیگیرد.

| قاعده | توضیح |
|---|---|
| چرا اینجا؟ | طبق بند ۵ و ۶ قوانین مخزن وردپرس، کد پولی نباید داخل افزونهی رایگان باشد؛ حتی اگر در دسترس نباشد. |
| چه چیزی اینجا میآید؟ | هر چیزی که فقط با لایسنس کار میکند: ابرها (S3/Drive/هاست دانلود)، ابر اختصاصی، زمانبندی پیشرفته، ریاستور درجا، مالتیسایت، بکاپ افزایشی، لایسنس. |
| وضعیت فعلی | فقط درایور S3 (کلاینت SigV4 + ذخیرهساز) که از هسته جدا شده تا نسخهی رایگان پاک بماند. |
| چگونه لود میشود؟ | فقط از `pro/autoload.php` در محیط توسعه و تستهای `tests/Pro`. |
| مقصد نهایی | مخزن/افزونهی جداگانه و سبک `backupino-pro` (به‌صورت یک افزونه مکمل / Addon برای افزونه پایه `backupino`) که از سایت رسمی توزیع میشود و از طریق فیلترهای مستند به هسته وصل شده و قابلیت‌ها را فعال می‌سازد. |

## نقاط اتصال (Extension points)

| فیلتر | کاربرد |
|---|---|
| `backupino_storage_drivers` | ثبت درایور ذخیرهسازی جدید (S3، Drive، FTP، …) |
| `backupino_stages` | افزودن مرحله به خط لولهی بکاپ |

مستندات کامل: [`docs/Dev/ARCHITECTURE.md`](../docs/Dev/ARCHITECTURE.md)
